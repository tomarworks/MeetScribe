#  MeetScribe

### AI-Powered Meeting Transcription & Analysis Platform

MeetScribe is an AI-powered meeting intelligence system that processes recorded meetings and transforms them into structured transcripts, summaries, and actionable insights.

---

##  Features

-  Meeting audio processing
-  Automatic speech transcription
-  Speaker-aware meeting analysis
-  AI-powered meeting summarization
-  Structured meeting insights
-  Interactive web-based interface
